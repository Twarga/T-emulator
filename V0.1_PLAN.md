# T-EMULATOR v0.1 — Implementation Plan
*PSP + XMB vertical slice. Done = picker → coldboot → XMB → game launches via PPSSPP → back.*

Stack: Rust + Slint. Built on tlab (headless), GUI tested on your laptop.

**Division of labor: I write all the code. You only run and test each phase's gate on your laptop.** Every phase ends with a `TEST:` line — that's your only job. Report pass/fail, I fix.

---

## Phase 0 — Workspace & scaffolding

- [ ] `cargo` workspace `t-emulator`; deps: `slint`, `tokio`, `reqwest`, `serde`, `gilrs`, `directories`, `rusqlite`
- [ ] `build.rs` + `slint-build` for .slint compilation
- [ ] Folder skeleton per PLAN.md: `src/adapters/`, `src/scanner/`, `src/skins/`, `ui/`, `assets/`
- [ ] Build script on tlab + `scp` to laptop workflow documented in `DEV.md`
- [ ] Hello-world Slint window — prove backend on Fedora/Wayland (fallback: `SLINT_BACKEND=winit`)

**Gate:** blank native window opens on laptop.
**TEST (you):** run the scp'd binary — a native window opens, no webview, no errors.

## Phase 3 — PPSSPP adapter

- [ ] `adapters/ppsspp.rs`: `install()` (fetch official release → `~/.local/share/t-emulator/emulators/ppsspp/`), `launch()` (game path + fullscreen), `write_defaults()` (Vulkan, 2x res)
- [ ] `xmb.play_game(path)` → adapter → on child exit, restore XMB

**Gate:** game → PPSSPP fullscreen → quit → back on XMB.
**TEST (you):** play Ghost of Sparta from XMB, quit mid-game, confirm you land back on XMB.

## Explicitly OUT of v0.1

Metadata/covers, manager pages, updates UI, controller remapping, save manager, per-game profiles, RPCS3, other skins, store, themes.

## Risks

1. **Wave fidelity** — biggest risk to "feels real"; port math, don't approximate.
2. **PPSSPP on Fedora** — manual smoke test (download + launch a game by hand) happens in Phase 0 BEFORE writing the adapter.
3. **Slint + Wayland gamepad** — verify gilrs under fullscreen Slint; X11 session fallback if broken.
