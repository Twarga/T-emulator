PSP · XMB SHELL · V0.1.0

A console in your pocket.
On your desktop.

T-Emulator boots a real PSP-style XMB shell on top of PPSSPP — games, settings and covers, all in one place. One window, controller-first.

Download for Linux Windows ↓ GitHub →

v0.1.0 · free & open source · PPSSPP auto-installs on first run

PSP XMB, for real

The crossbar, the wave, the clock. Settings edit ppsspp.ini directly — backend, resolution, filters, OSD — no fake toggles.

Controller-first

Plug in a USB pad and it just works — bindings are written into PPSSPP automatically. Drive the whole UI without a keyboard.

Real covers & photos

Every console shows its product shot; every game shows its box art, fetched from libretro-thumbnails when missing.

Error cards, not toasts

Missing emulator, deleted file, no Vulkan driver — you get a card with a fix button, not a message that vanishes.

Inside

The same story at every step — launcher to shell to game.

Get it

v0.1.0 — the first release. PSP only for now; PS3, GameCube and PS2 shells come next.

  • Needs PPSSPP — installs itself from the Downloads tab on first launch.

  • Controls: arrows/dpad move · Enter/A select · Esc/O back · Tab/shoulders switch section · / search.
  • Checksums ship as SHA256SUMS.txt on the release page.
